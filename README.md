# 📊 Interactive Business Dashboard

## Project Overview

An interactive executive business dashboard built using **Python, Pandas, Streamlit, and Plotly** to analyze business performance and visualize key organizational KPIs.

The dashboard provides interactive filtering, KPI cards, trend analysis, profitability insights, product performance analysis, and detailed data exploration.

## 🎯 Objectives

- Create an interactive executive dashboard
- Visualize important business KPIs
- Analyze revenue and profit trends
- Provide interactive Year and Month filters
- Analyze product-level performance
- Explore relationships between product price and revenue
- Present business insights through interactive visualizations

## 📌 Executive KPIs

The dashboard includes:

- **Total Revenue**
- **Total Orders**
- **Average Order Value (AOV)**
- **Total Profit**
- **Profit Margin**

## 📈 Dashboard Features

### 🔎 Interactive Filters

- Year filter
- Month filter

### 📊 Visualizations

- Revenue & Profit Trend
- Revenue Distribution
- Profit Distribution
- Price vs Revenue Relationship
- Profit Margin Analysis
- Top Products by Revenue

### 📋 Data Exploration

The dashboard provides access to the filtered dataset for detailed analysis.

## ▶️ Run Locally

Install the required libraries:

    pip install -r requirements.txt

Run the dashboard:

    streamlit run app.py

The application will open in the browser at:

    http://localhost:8501
